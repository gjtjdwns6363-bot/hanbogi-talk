스페인어로 ‘체크아웃할게요’

께리아 아세르 엘 체까웃
Quería hacer el check-out.
ke-RI-a a-THER el che-KAUT

🏨 호텔에서 쓰는 다른 스페인어

예약했어요 뗑고 우나 레세르바체크인할게요 께리아 아세르 엘 체낀체크아웃은 몇 시예요? 아 께 오라 에스 엘 체까웃짐 좀 맡아 주세요 메 뿌에데 과르다르 엘 에끼빠헤수건 더 주세요 메 뿌에데 다르 마스 또아야스에어컨이 안 돼요 엘 아이레 아꼰디시오나도 노 푼시오나뜨거운 물이 안 나와요 노 살레 아과 깔리엔떼방 열쇠를 잃어버렸어요 에 뻬르디도 라 야베 데 라 아비따시온조식은 몇 시예요? 아 께 오라 에스 엘 데사유노늦게 체크아웃할 수 있어요? 뿌에도 데하르 라 아비따시온 마스 따르데방 청소 해 주세요 뿌에덴 림삐아르 라 아비따시온, 뽀르 파보르

자주 묻는 질문

스페인어로 '체크아웃할게요'는 어떻게 말해요?

Quería hacer el check-out. (ke-RI-a a-THER el che-KAUT)라고 하고, 한국어로는 '께리아 아세르 엘 체까웃'에 가깝게 읽어요.

'께리아 아세르 엘 체까웃' 발음은 어떻게 들어요?

이 페이지의 ▶ 듣기 버튼을 누르면 브라우저 스페인어 음성으로 읽어 줍니다. 🐢 천천히 버튼은 느린 속도로 들려줘요.
